Client Integrations Zero-Config Setups
1. Claude Desktop (Developer Mode)

1. In Claude Desktop, click Help > Troubleshooting > Enable Developer Mode.
2. Open Developer > Configure Third-Party Inference → choose Gateway.
3. Configure the Gateway URL and Master Key:

http://localhost:8080/v1
llm-router-secret-key-12345
2. Claude Code CLI

Route the official Anthropic Claude Code terminal interface directly through your router:

PowerShell: $env:ANTHROPIC_BASE_URL="http://localhost:8080" ; claude
Bash: export ANTHROPIC_BASE_URL=http://localhost:8080 ; claude
3. OpenAI SDK / Cursor / Continue.dev

Standard OpenAI SDK compatibility for scripts, agents, and IDE tools:

client = OpenAI(base_url="http://localhost:8080/v1")
