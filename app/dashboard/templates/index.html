1. Claude Desktop (Native Third-Party Gateway)

Connect Claude Desktop natively using Developer Mode:

  1. In Claude Desktop, click Help > Troubleshooting > Enable Developer Mode.
  2. Click the new Developer menu > Configure Third-Party Inference.
  3. Set Connection Type to Gateway.
  4. Set Gateway Base URL to:
http://localhost:8080/v1
  1. Set Gateway Credentials to Static API Key and enter your Master Key:
llm-router-secret-key-12345

2. Claude Code CLI

Run the official Claude Code CLI entirely for free through your local gateway:

# PowerShell $env:ANTHROPIC_BASE_URL="http://localhost:8080" $env:ANTHROPIC_API_KEY="llm-router-secret-key-12345" claude
# Bash / Zsh export ANTHROPIC_BASE_URL=http://localhost:8080 export ANTHROPIC_API_KEY=llm-router-secret-key-12345 claude
